# Peridot Essential 1.18.7

Community build for POCO F6 (`peridot`), Snapdragon 8s Gen 3 (`SM8635`),
Adreno 735. Protocol `peridot.4`.

This release corrects status claims after device testing. No control path,
frequency table or OPP limit changed from 1.18.6.

- Touch control: the tested peridot vendor stack does not expose the
  TouchFeature AIDL service. The screen now reports the engine as unavailable
  and writes no touch mode; 125/250 Hz remain inherited labels, not measurements.
- Charging power profiles remain kernel dependent and still require adaptation.
- Memory DVFS and UFS scheduler controls are not device-validated yet; their
  nodes are probed and reported as unavailable when absent.
