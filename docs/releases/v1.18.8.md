# Peridot Essential 1.18.8

Community build for POCO F6 (`peridot`), Snapdragon 8s Gen 3 (`SM8635`),
Adreno 735. Protocol `peridot.5`; version 1.18.8 / 11808.

Hardware interface alignment with the peridot LineageOS 23.2 device kernel.

- Memory DVFS: DCVS boost floors, not the retired per-device devfreq rails.
- Storage: `1d84000.ufshc` devfreq scheduler control.
- Charging: `fastcharge_enable` 0/1/2, no bypass. UI profiles 0 (OEM),
  33 (Fast), 90 (Super Fast).
- Touch: TouchFeature AIDL primary, HTPR boolean (`bump_sample_rate`) fallback.
- New read-only probe: `GET hardware.contract` for on-device validation.

**Before flashing this or any later build, run `GET hardware.contract` and
confirm the reported UFS path, DCVS rails, fastcharge node and touch backend
match your device.** On-device validation of these nodes is separate from the
posted release and is tracked via the probe output.

## Self-check

On a rooted sold device, with the daemon running and the module loaded:

```
adb shell su -c 'peridot_ctl GET hardware.contract'
```

The reply must list `dcvs_mask`, `ufs_devfreq`, `ufs_luns`, `fastcharge`,
`touch_backend` and their discovered nodes. If a node is absent, the probe
reports it and the corresponding control stays unavailable.
