# Peridot Essential visual identity

The master peridot-icon-master.png was generated using the integrated image tool
with the supplied Snapdragon 8s Gen 4 image as a reference. The design combines
a red dragon/flame forming an O, an peridot-black background, gold edges and a
silhouette that remains readable at launcher sizes without text.

Assets include legacy 48/72/96/144/192 px icons, round variants and an adaptive
icon with a black background and inset foreground. ui/flutter/assets/app_icon.png
is the 512 px logo used by the interface. ImageMagick handles packaging scales
and masks; it was not used to generate the illustration.
