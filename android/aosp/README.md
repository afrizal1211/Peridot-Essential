# Peridot integration templates

These files use the Peridot identity, but native policy still requires adaptation
and validation against the actual POCO F6 vendor. They are not a validated,
ready-to-install AOSP bundle.

The prepared route uses the root module. Maintainers should review
[ROM_INTEGRATION.md](../../docs/ROM_INTEGRATION.md) and validate domains, contexts,
Xiaomi services, KGSL/cpufreq/Sconfig access and transport authentication.
