# Peridot tile experiment

Isolated quick settings tile experiment. It does not replace normal packaging
or constitute a newly validated POCO F6 feature. The current application uses a
small framework adapter for PeridotActivity and BypassTileService.

For product builds, see [BUILDING.md](../../../docs/BUILDING.md).
Bypass requires actual kernel support; see
[BYPASS_CHARGING.md](../../../docs/BYPASS_CHARGING.md).
